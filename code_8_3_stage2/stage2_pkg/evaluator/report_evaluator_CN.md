# 0. 结论

**数值验收：通过。** §9 的三类数值标准（离散实现、数值收敛、MC 一致性）全部满足，见 `logs/analysis.log` 的 `CRIT` 行。按 §9 的固定措辞：

> 评价器在四个测试输入上与 MC 在其分辨率下未发现显著差异（199 项正式比较，阈值按 202 项校正的近似 $t_{19}$ Bonferroni）；网格 $\sigma/12$ 与 $\sigma/24$ 之间 $\Delta m_D$ 的变化不超过 0.002 nat、$m_E$ 不超过 0.002。

没有输入触发 $n=48$，四个输入都在 $n=24$（稳定性比较 12/24）上受验。

**耗时线：通过，但余量很小。** 版本 B、$n=24$ 的稳态单次耗时四个输入为 12.25–14.88 s，最大值 14.88 s（输入 N）低于 15 s 的 numba 线。四项都通过，按 §9 可以写"评价器验收通过"。耗时只测了一次（每个评价一次），单元测试与正式运行之间同一评价的耗时有几个百分点的差别（B/U/$n=24$：12.10 s 与 12.73 s，`logs/unit_tests.log` 与 `logs/run_all.log`），所以 N 的 14.88 s 离线很近，这一条的通过不稳固。

**三个问题的简答。**

1. **与 MC 是否一致。** 版本 B、$n=24$ 对新 MC（种子 20261019，$R=10000$，20 批 × 500，四输入公共随机数）：199 项正式比较中 $|z|>4.496$ 的为 0 项，最大 $|z|=2.665$，$|z|>2$ 的 7 项，$|z|>3$ 的 0 项。这是"在当前 MC 分辨率下未发现显著差异"，不是"无偏"：MC 的分辨率是 $\log\det$ se 0.0018–0.0025 nat、$\mathbb E[N]$ se 0.0136–0.0190、配对 $\Delta m_D$ se 0.0026–0.0040 nat（`logs/mc_reference.log`）。
2. **数值稳定性。** 版本 B 在三档网格上观测阶 $p_{\rm obs}$ 在 1.984–2.007 之间（绝对量与相对量）；$\sigma/12\to\sigma/24$ 的变化：$|\Delta m_D|\le2.7\times10^{-4}$ nat、$|\log\det|\le6.4\times10^{-4}$、$|\mathbb E[N]|\le3.8\times10^{-3}$、$|m_E|\le3.0\times10^{-5}$、$\|J_{24}^{-1/2}J_{12}J_{24}^{-1/2}-I\|_2\le1.4\times10^{-4}$，都在 §6 的工程目标内。尾部裕量 $8\Delta\to16\Delta$ 所有量的最大变化 $7.5\times10^{-12}$。这些是网格研究给出的数值稳定性，不是误差上界。
3. **耗时。** 版本 B：$n=12$ 均值 6.67 s，$n=24$ 均值 13.26 s（最大 14.88 s）。搜索一轮约 3000 次评价，按 $n=24$ 均值折算 39790 s ≈ 11.05 h，按最大值折算 12.40 h（单进程单核，`SEARCH-ROUND` 行）。

# 6. 实现中的选择与偏离（供审核）

1. **A、B 的节点。** 方案 §4 写 $z_i=z_0+ih$。第一次单元测试（`logs/unit_tests_run1_arange_grid.log`）对 A、B 和测试 (b) 用了原型的 `np.arange`，其步长 $\mathrm{fl}(z_0+h)-z_0$ 与 $h$ 有约 $3\times10^{-12}$ 的相对差，测试 (b) 因节点位置累积误差差了 $-1.8\times10^{-12}$。之后 A、B 改为 $z_0+ih$（测试 (b) 用 $jh$），v0 保留原型的 `arange`，节点数 $G$ 不变；第二次全部通过（`logs/unit_tests.log`）。`config.json` 的 `grids.nodes` 同时写了两种形式，没有改动冻结的配置。
2. **$c_k$ 的实现。** 方案要求 A、B 用 numba，又要求 $c_k$ 沿用已过审的 `mc83.cfun`。本实现在 numba 中做递推，每步回到 Python 用原样的 `cfun` 在 $m_k\ne0$ 的下标区间上求值（区间外 $m_k=0$，结果精确不变）。因此 numba 耗时线针对的是这种混合实现。
3. **$1-\hat P$ 与 $\sum_i m_i(1-\omega_{ij})$** 直接按 $|i-j|>M$ 的前缀和加端点权重求，不用 $1-\hat P$ 相减；前缀数组单调，差值在浮点下非负，$m\ge0$ 因此逐位成立。
4. **尾部检查**对四个输入都做（相对量需要 16Δ 下的 U），版本 B、$n=12$。
5. **$c_k$ 不变量**在每一步的全部网格节点上检查（不计时）；A、B 网格相同、都用 `cfun`，共用一次检查结果。
6. **辅助检查 $0\le w_k\le1$** 不是方案的三条不变量之一，只作附加记录；A、B 全部成立，v0 因负质量在个别步不成立。
7. **耗时剖析**（`profile_runtime.py`）是为回答 P7 的"为什么"另加的诊断，不改变任何结果。
