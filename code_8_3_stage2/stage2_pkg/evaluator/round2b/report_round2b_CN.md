# 0. 结论

1. **两个对偶估算值。** 新网格（$h=\sigma/30$，$L=137$）上：一维无加速度约束 $\widetilde S_{\rm 1D}=1210.815$（$\lambda^\*=1.9185615985194624$，$\epsilon_\lambda=10^{-2}$）；二维加速度约束 $\widetilde S_{\rm acc}=619.129$（$\lambda^\*=0.9381038031641779$，最终 $\epsilon_\lambda=2.5\times10^{-3}$，细化 1 次）。**加入加速度限制后，同一离散模型上的对偶估算值下降 591.686**（$\widetilde S_{\rm 1D}$ 的 48.87%）。两者都是估算值。
2. **所选策略（最终 $\lambda^\*$）前向**（二维离散模型）：$S=1163.780$，$\mathbb E[N]=897.479$，**不满足预算**（$\mathbb E[N]-B=+580.587$）。按方案如实报告，未为满足预算而调整 $\lambda$。该确定性策略位于对偶函数折点的一侧；细化前 $\lambda^\*$（$\epsilon_\lambda=10^{-2}$）下的确定性策略在另一侧（$S=398.171$，$\mathbb E[N]=81.407$），已被取代，见第 3 节。
3. **T3（$k=2..K$ 时间平均）。** 二维（最终 $\lambda^\*$ 策略）：$\overline{\Pr}\{18\le|\delta|/\sigma\le19\}=2.37\%$，低速占比 $0.00\%$。一维无约束（其 $\lambda^\*$ 策略）：$74.39\%$、$74.38\%$。二维的这两个数随 $\lambda^\*$ 落在折点哪一侧而整体改变（细化前为 $37.22\%$、$77.65\%$）。
4. **$S_{\rm found}=491.787$**（按数值判据可行的已评估候选中最大的 $S$ 评价值；来自随机起点 R01 的第 145 次评价；$\mathbb E[N]=316.841$，比 $B-\tau_N$ 低 0.0108）；$p=(0.2483,\,0.0085,\,0.4127,\,0.3304)$，$\chi=(0.5212,\,5.0438,\,5.7997,\,3.0479)$ rad；$\Delta m_D=-4.427$，$m_E=0.0297$。共 8433 次评价，1.22 h。它既不是原连续问题的严格下界，也不是族内最大值。
5. **$\rho=25.894\%$，误差带 $\pm2.381$ 个百分点（$\epsilon_\lambda=2.5\times10^{-3}$），细化 1 次，分支：未定**（$10\%\le\rho\le35\%$）。细化前 $\rho=25.947\%\pm9.524$，区间 $[16.42\%,\,35.47\%]$ 碰到 35% 边界，按规则细化。网格误差未计入误差带。
6. **预测**：T1、T2、T5 对；T3 对（按规则取最终 $\lambda^\*$ 的策略；该结论不稳健，见第 4 节）；T4 部分对（三项中一项对）；T6 部分对（二维外层 3–6 h 错）。见第 7 节。
