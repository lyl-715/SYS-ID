# 0. 结论

1. **四项检查全部通过**（估算报告的前提）：B1 最大相对差 $2.37\times10^{-15}$；B2 的两个不等号对 8 个输入、两个 $A$ 都成立，P5514 在 $A_1$ 下第二个不等号的差为 $-2.84\times10^{-14}$；B3 二维 DP 逐位复现 2b 轮的 $\widetilde V$；B4 最大相对差 $4.36\times10^{-15}$。
2. **C3（估算，nat，$\Delta m_D$ 尺度）**：直接路线二维 $A_1$ 为 **4.385**，二维 $A_2$ 为 5.261，一维 $A_1$ 为 15.218，一维 $A_2$ 为 17.419；$S$ 路线为 **3.776**。直接路线的最好值（二维 $A_1$）比 $S$ 路线**高 0.610 nat**。
3. **预测**：L1、L6、L7 对；L4 对（按二维模型读，DECISION C-8）；L3 部分对（$S$ 路线数值对，"直接路线低至少 0.5 nat"错）；L2、L5 错。
4. **按方案 §5 读**：两个固定 $A$ 下，直接路线都不比 $S$ 路线低。这个结论只对本轮的两个固定 $A$ 成立：$\mathcal D$ 对 $A$ 的最小化没有做（方案 §7）。B2 显示，固定 $A$ 的线性化在已知输入上的松弛量是 0.09–1.10 nat，与上面的 0.610 nat 同量级。所以本轮的数据不能把"方向信息"的作用和"固定 $A$ 的线性化损失"分开（见第 3 节末）。
