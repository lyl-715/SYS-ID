# Literature comparison: input design for event-triggered / quantized / censored identification

Read on 2026-10-14. 8 items read in full and 5 from the abstract only (marked **abstract only**).
URLs, access status and refused hosts are listed in `sources.md`. No sentence is quoted; everything is
paraphrased.

## Note A — Kawaguchi et al. (2017): asymptotic variance and the comparison with periodic ("Riemann") sampling

Setting:

- The output is checked on a clock t_k = kT (k = 0..N): `y_k = ŷ_k(θ) + w_k`, with `w_k ~ N(0, σ²)` white.
- Fixed levels η_1 < … < η_M (in the example, equispaced with spacing d). The band index m_k satisfies
  η_{m_k} ≤ y_k < η_{m_k+1}, and y_k is sent iff m_k ≠ m_{k−1}.
- `ŷ_k(θ) = G(p, θ)u(t_k)` and `φ_k = ∂ŷ_k/∂θ`.

Paraphrasing their Theorems 1–2 in this notation (P_k(m) is the probability that y_k lies in band m):

    a = (η_m − ŷ_k)/σ,  b = (η_{m+1} − ŷ_k)/σ,  φ_N / Φ = standard normal pdf / cdf
    P_k(m)  = Φ(b) − Φ(a)
    σ² h_k(m) = [1 − P_k(m) + b φ_N(b) − a φ_N(a)]          (sent: exact value, outside the band)
              + [φ_N(a) − φ_N(b)]² / P_k(m)                  (not sent: "still in band m")
    I(θ*) = φ_0 φ_0ᵀ/σ² + Σ_{k=1..N} Σ_{m=0..M} P_{k−1}(m) h_k(m) φ_k φ_kᵀ
    Cov(θ̂_ML) ≈ I(θ*)⁻¹
    E[#sends] = N + 1 − Σ_{k=1..N} Σ_m P_{k−1}(m) P_k(m)

- The double sum averages over the band of the previous clock step. Its law is simply P_{k−1}(m), because the noise
  is white and the grid is fixed.
- The two brackets are exactly `cev` and `cno` in the repo's `cfun` (`mc83.py`), where the band is instead
  (r−Δ, r+Δ) around the last sent value r.
- By the data-processing inequality, σ²h_k(m) ≤ 1 (see summary §4).

Comparison with periodic sampling:

- **Baseline.** Periodic subsampling of the same clock with period k_r·T, using only the kept values (output-error
  fit). k_r is chosen so the number of kept values equals the expected number of Lebesgue sends.
- **First-order example.** b/(s+a) with a = b = 1, white Gaussian input held every 0.1 s, σ = 0.1, T = 0.1 s,
  100 s (N = 1000), d = 0.23, about 500 sends, 1000 runs.
  - The censored ML is unbiased; output-error on the sent samples alone is visibly biased, because whether a
    sample is sent depends on its noise.
  - As d or k_r grows, the Lebesgue variance degrades more slowly than the periodic one at the same count.
- **Random systems.** 1000 random stable first-order and 1000 second-order systems, with d = 2ασ_y, σ² = βσ_y²,
  α, β ~ U[0, 1]. The generalised variance det(I⁻¹) was smaller under Lebesgue sampling in every case (FIM
  comparison only).
- **Caveat.** The count is equal, but the information available is not: the Lebesgue side also uses the
  censoring information at all N clock steps, while the periodic side uses only the kept values.

## Note B — direct links to this repository

- The §8 setup in `code_8_3_stage2/stage2_pkg/mc83.py` matches Dozzi et al.'s benchmark: system
  2/(s+1)², window T = 5 s, tones {3√2, 3π, 12, 12.3} rad/s, FRF-value parametrisation. Their D-optimal
  deterministic sampling sequence is therefore a ready baseline for SoD at equal N.
- The repo's per-clock-step information weight `cfun` (c_ev + c_no) is Kawaguchi et al.'s h_k with the SoD
  band in place of the fixed band. Kawaguchi's closed-form average over the previous band does not carry over;
  the repo averages over noise realisations instead.
