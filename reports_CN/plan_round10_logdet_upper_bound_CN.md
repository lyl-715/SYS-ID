# Round 10 方案：给定预算下 log det J 的名义最优值与当前表的认证差距

状态：**已冻结（2026-11-08，第二轮审稿两处修正并入）**。目的：回答"7.83 离可能的最好差多少"，答案是一个宽度不超过 0.01 nat 的认证区间 [g_L, g_U]。

文献定位：预测中心窗口 + 删失 ML + CRLB 的框架已有——You, Xie, Song (IEEE TSP 2013) 给出确定性残差阈值调度下的 CRLB 并设计渐近达到它的自适应调度；Han, You, Xie, Wu, Shi (IEEE TSP 2015) 在发送率约束下优化调度参数（谱半径准则，SDP 松弛），并证最优参考值即预测输出。本轮以这些预测中心窗口的研究为背景，构造用于本文性能比较的 D 准则基准，不主张其理论新颖性；本文的贡献在 SoD 结构（窗口围绕上次发送值）一侧。基准量化的是当前 SoD 表与更大窗口类的名义最优之间的差距，不把该差距归因于结构或设计。

## 1. 要证的不等式与适用范围

**窗口类 W**：第 k 步的区间窗口由时刻与**接收端已知的历史**（已发送的值与沉默事件）确定。这覆盖本文的窗口表（表只看 k 和 r_k），但**不**覆盖用到未发送测量的规则（如 Dozzi 触发中依赖全部测量的 z_k 状态）——窗口若依赖未发送的测量，沉默事件会携带那些测量的信息，命题 2 的逐步累加公式不再覆盖全部信息，上界不成立。这一限定写进定理陈述。

对 W 中任何规则，在 Σ_{k≥2} E[q_k] ≤ B − 1 下，

log det J ≤ UB(B) := max_{q̄} f(q̄)，f(q̄) = log det( σ⁻² [ h₁h₁ᵀ + Σ_{k≥2} c_max(q̄_k) h_k h_kᵀ ] )，
约束 Σ_{k≥2} q̄_k ≤ B − 1，0 ≤ q̄_k ≤ 1，

c_max(q) = q + 2a·φ(a)，a = Φ⁻¹(1 − q/2)，即固定发送概率 q 时对称窗口的信息权重。

三步：
- **引理 A（固定 q 时对称窗口信息最大）。** 沿约束 Φ(β) − Φ(α) = 1 − q 有 dc/dα = φ(α)(β − α)[2μ_T − (α + β)]，μ_T 为截断均值。记中点 m = (α+β)/2、半宽 d = (β−α)/2，则 (1−q)(μ_T − m) = ∫₀^d t[φ(m+t) − φ(m−t)] dt；m > 0 时 (m+t)² > (m−t)²，被积函数为负，μ_T < m，故 dc/dα < 0；m < 0 时相反。所以 c 在 α = −β 处取最大。解析证明，不需要区间算术。
- **引理 B（c_max 凹）。** dc_max/dq = a² = [Φ⁻¹(1 − q/2)]²，随 q 递减。
- **第三步。** w_k = E_r[c(α_k, β_k)] ≤ E_r[c_max(q_k(r))] ≤ c_max(q̄_k)（引理 A，再 Jensen 用引理 B）；J ⪯ σ⁻² Σ c_max(q̄_k) h_k h_kᵀ（Loewner 序），log det 单调。

**UB 是可达的，因此是 W 类的名义最优值，不只是松上界。** 取最优解 q̄*，用以名义输出为中心的时变窗口 [x̄_k − σa(q̄*_k), x̄_k + σa(q̄*_k)]（只依赖时刻，属于 W），在名义真值处每步恰得 q = q̄*_k、c = c_max(q̄*_k)，信息矩阵正好等于 UB 对应的矩阵。所以 g = UB − log det J_表 的含义是"当前 SoD 表到该窗口类名义最优的距离"。

f 是凹的（log det 对矩阵凹且 Loewner 单调，c_max 对 q 凹），全局最优可算。

## 2. 怎么算、怎么认证

- 变量 q̄ ∈ ℝ^{K−1}，K = 5000。解析梯度 ∂f/∂q̄_k = σ⁻² h_kᵀ J⁻¹ h_k · a_k²。
- 求解：投影梯度上升；KKT 水填充（未饱和分量满足 σ⁻²h_kᵀJ⁻¹h_k·a(q̄_k)² = λ）作交叉核对（DECISION 10-1）。
- **认证。** 优化器返回的 f(q̂) 只是 UB 的下界。用凹函数的切平面：在可行内点 q̂ 处取 ∇f(q̂)，

  U_cert = f(q̂) + max_{v∈C} ∇f(q̂)ᵀ(v − q̂)，

  内层是线性预算分配：按梯度降序逐个分配到 1，最后一个分量取分数，精确可算。于是 f(q̂) ≤ UB ≤ U_cert。**停止标准：U_cert − f(q̂) ≤ 0.01 nat。** 不用 Lagrangian 代值，不用区间算术。
- **差距的认证区间。** 记 I_表 = log det J_表，g_L = f(q̂) − I_表，g_U = U_cert − I_表。真实差距 g_* = UB − I_表 ∈ [g_L, g_U]，区间宽 ≤ 0.01 nat。正文报这个区间；只报一个数时报"距名义最优不超过 g_U nat"，对应 D-efficiency 的认证下界 e^{−g_U/9}。不把 U_cert 单独称为最优值。
- 预算两档。名义预算 B = 316.8921168493721，读自 `round4/results/mc.json → U/SoD → EN_eval`，316.892 是显示用的取整值；T4 预算 B = 262.7986258567231（`round6/results/scan_U_W_m020.json → runs[1] → EN`，取整 262.8）。
- 顺带输出：q̄*_k 的时间分布，与名义表的实际发送分布（Σ_i m_{k,i} q̂_{k,i}）同图。

## 3. 单边参照值 V₁

把 c_max 换成单边窗口的 c₁(q) 再算一遍，记 **V₁：理想单边窗口参照值**。理想单边窗口与 SoD 窗口不是包含关系（前者无参考值约束，后者在部分状态可用两侧边），所以 UB − V₁ **不是** SoD 结构代价，V₁ − log det J_表 **也不是**设计可追回的收益。V₁ 只报位置，不作归因（审稿第 4 条；撤回 11 月 8 日回复中的三段拆分）。

## 4. 检查

1. 按预算分别匹配：对每个预算 B，U_cert(B) 不低于所有已确认满足该预算的比较策略的信息值——名义预算下对当前表（7.83 + log det J_SoD）与常数 SoD 基线；B = 262.8 下对 T4 与满足该预算的基线。不要求小预算的上界超过用了大预算的策略。不满足即推导或代码有错，停。
2. q̄_k ≡ 1 时 f 等于全采样信息 log det(σ⁻² Σ h_k h_kᵀ)。
3. 标量版（h_k h_kᵀ → 1，目标 → Σ c_max(q̄_k)）：预算 316.892 下复现 S_sym = 1636.15、S_one = 1346.82（审稿已独立算得）。
4. 解析梯度对有限差分。
5. 引理 A 的数值复核：q 细网格上扫 α，最大值均在对称处。

## 5. 预测（冻结后提交）

- ΔI_UB = U_cert − log det J_SoD ∈ [10, 14] nat（名义预算）。
- g_* ∈ [2, 6] nat（认证区间宽 ≤ 0.01）；D-efficiency 认证下界 e^{−g_U/9} ∈ [51%, 80%]。
- V₁ − log det J_SoD ∈ [8.5, 11]。
- q̄*_k 不均匀：h_k 沿 J_SoD 薄弱方向的时刻拿到更多预算。

## 6. 判定（审稿第 4 条的表）

| 认证结果 | 可得结论 |
|---|---|
| g_U < 2 nat | 当前表距名义最优不足 2 nat（D-efficiency 认证下界 > 80%） |
| g_L > 4 nat | 当前表距名义最优超过 4 nat（D-efficiency < 64%），值得探索改进（Round 11：边参数化、迭代 A） |
| 区间跨越判定阈值 | 收紧求解间隙后再判定 |
| V₁ 高于或低于当前表 | 只说明相对理想单边策略的位置，不用于判定差距来源 |

不写"差距小故剩余差距来自 SoD 结构"：差距小证明接近最好，不证明剩余差距的原因。

## 7. 报告口径（审稿第 5 条）

主结果报差距区间 [g_L, g_U]（nat），或"不超过 g_U nat"。百分比用 D-efficiency 认证下界 exp(−g_U/9)（差 2 nat ≈ 80.1%，差 4 nat ≈ 64.1%）。7.83/ΔI_UB 可报，只能称"相对常数 SoD 的 log det 增益比例"，不称"达到上界的 X%"。
