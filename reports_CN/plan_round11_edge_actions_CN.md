# Round 11 方案：动作集按"边相对预测输出"参数化 + 迭代切点 A，重做名义设计

状态：**已冻结（2026-11-09，外审三条修正并入）**。前提：Round 10 给出名义预算下当前表（U/W）距窗口类 W 名义最优 g ∈ [4.037, 4.041] nat（D-efficiency ≥ 63.8%），落在"值得探索改进"一行。本轮只动设计侧的两样东西，量它们能追回多少。

## 1. 问题

同一个场景（第 II-D 节）、同一个名义预算 B = 316.8921168493721（`round4/results/mc.json → U/SoD → EN_eval`）、同一个 SoD 结构（窗口围绕参考值 r 开，评价器与 DP 的状态、转移不变），改两样：

- **动作集**：从"半宽相对 r 取 2–40σ"改为"边相对预测输出 x̄_k 取位置"。
- **切点**：从只用 A = J_SoD⁻¹ 改为迭代 A ← J(T)⁻¹，按真实 log det 验收。

报四格：{旧动作集，新动作集} × {A₀，迭代 A}，每格一个 ΔI 和一个到 UB 的差距 g′ = U_cert(B) − I_表。U_cert 取 Round 10 的 209.07220154478713（`round10/results/round10.json → budgets.B316.u_cert`）。

不碰：预算、σ、输入、网格步长、测量核、转移公式、估计器、序贯流程、第 V 节的失配与余量。**要改的**：参考值状态支撑与动作边界索引范围（见 §2.1）——旧代码只读，改动在 `round11/` 的独立实现里。

## 2. 新动作集（DECISION 11-1）

动作为一对边位置 (e⁻, e⁺)，e ∈ E = {1, 1.25, 1.5, 1.75, 2, 2.25, 2.5, 3, 4, ∞}（σ 单位），100 个动作。给定节点 r_i 和预测输出 x̄_k：

- 下边 = min(x̄_k − e⁻σ, r_i − 2σ)，上边 = max(x̄_k + e⁺σ, r_i + 2σ)；e = ∞ 表示该侧只保留 r ∓ 2σ。
- 两条边向外取整到最近网格节点（δ_g = σ/24），半宽 L = r_i − 下边、U = 上边 − r_i，均 ≥ 2σ = 48 格。

理由：DP 真正关心的是边相对 x̄_k 的位置（第 IV-E 节：朝向输出的边在外约 1.9σ），用半宽参数化它要靠 r 间接够到，离输出远了就被 40σ 上限卡住（18% 预算变成主体发送）、近了又受 2σ 步长限制（±1σ 散布）。按边参数化，两个问题一起消失，而且动作数从 400 降到 100。

"距 r 至少 2σ"保留原动作集的下限语义，使两套动作集在 r 贴近 x̄_k 时可比；替代方案（1σ 或不设）作 DECISION 11-1 的备选，本轮不跑。

### 2.1 支撑（本轮的主要实现改动，DECISION 11-3）

新动作的半宽可以超过 40σ（r_i = x̄_k + 50σ、e⁻ = 2 时 L = 52σ），而冻结代码写死了：最大半宽 40σ（边界索引扩展量 X = 960）、参考值状态限于 x̄_k ± 88σ、下一步支撑之外的价值置零。只加大索引数组不够：新窗口可以在包含当前输出的同时保留远处的旧参考值，持续沉默时 r 不更新，原来随 x̄_k 移动的状态支撑会把仍有质量的参考值切掉。

要求：
- 网格步长 δ_g、测量核（x̄_k ± 39σ 精确为零）、转移公式 (10) 不变。
- **参考值状态支撑与测量核支撑分开处理。DECISION 11-3（审稿定）：状态支撑取整条设计网格**（覆盖预测输出范围并向两端各延伸 8Δ*，与第 IV-C 节一致），DP 与前向评价都用它。不按某张候选策略前向得到的非零质量裁剪 DP 状态：DP 要比较不同策略，裁剪可能提前排除其他策略能到达的状态；全网格也便于回归验证。可能停留的旧参考值全部保留。
- 动作边界索引范围按网格全宽取，不再以 40σ 封顶。
- 守恒断言照旧：每步质量守恒、非负、**支撑边界质量为零**；任何一条失败即停。
- 回归门槛（§5.1）仍然成立：新实现喂旧动作集时，参考值质量永远不会超出旧的 ±88σ（旧动作集下 79σ 外必发送），所以逐位复现是对新支撑实现的直接检验。

**同一 DP 代码跑旧动作集**：把 (L, U) ∈ {2σ,…,40σ}² 作为动作直接送入同一条转移与得分代码，必须逐位复现 Round 4 的名义表（ΔI = 7.83，E[N] = 316.6035659260541）。这是本轮的回归门槛，不过则停。

## 3. 迭代 A（DECISION 11-2）

- 第 0 轮：A₀ = J_SoD(θ*)⁻¹，价格扫描同第 IV-D 节，得 T₀，评价器算真实 I(T₀)。
- 第 j 轮：A_j = J(T_{j−1})⁻¹，γ_k、γ̄ 重算，扫描得 T_j，算 I(T_j)。
- 接受规则：I(T_j) > I(T_{j−1}) + 0.05 nat 才接受并继续；否则停，取上一张。最多 3 轮。
- 每轮扫描 10–12 次 DP；新动作集下每次 DP 预计 < 10 s。

## 4. 要报的数（每格）

- ΔI = I(T) − I_SoD；E[N]（σ/24 设计值与 σ/120 复核值，复核值必须 ≤ B）；g′ = U_cert − I(T)；D-efficiency 下界 exp(−g′/9)。
- 窗口形状：朝向输出的边相对 x̄_k 的质量加权中位数与 10–90% 范围；按偏移分段的发送数与每次发送的信息（同 `cap_cost_by_offset.py` 的口径），看主体发送占比从 18% 降到多少。
- 切线高估量，**随切点定义**：第 j 轮参考 T_ref,j（第 0 轮为常数 SoD，之后为上一张被接受的表），E_j(T) = tr(J_ref,j⁻¹ J(T)) − p − [I(T) − I(T_ref,j)]。沿用 DP 存档的 F（只累计 k ≥ 2）时写成 E_j(T) = F_j(T) + γ_{1,j} − p − [I(T) − I(T_ref,j)]。不能把"切点变化"混进高估量。
- 迭代 A 的每轮 I(T_j)。

主结果一张表：四格 × {ΔI, g′, D-eff, 主体发送占比}。

## 5. 检查

1. 回归：新代码 + 旧动作集逐位复现 Round 4 名义表（表项、E[N]、ΔI）。
2. 每张表前向 = 后向（总得分一致到 1e-12）。
3. 守恒、非负、支撑断言。
4. 最终表的 Monte Carlo 核对：10⁴ 条轨迹，E[N]、S、log det J 均在统计误差内。
5. 新动作集下每个 (k, i) 的 L、U ≥ 48 格，且边落在网格节点上。
6. I(T) ≤ U_cert（Round 10 的界必须盖住新表；不盖住即 Round 10 或本轮有错，停）。

## 6. 预测（冻结后提交）

- 新动作集 + A₀：ΔI ∈ [8.5, 10.0]（追回 0.7–2.2 nat）；主体发送占比 < 5%；近边位置 10–90% 范围收窄到 1.5–2.3σ。
- 迭代 A 在两种动作集下各加 0–0.5 nat；第 2 轮后不再接受。
- 旧动作集 + 迭代 A：ΔI ∈ [7.8, 8.3]。
- 最好一格：g′ ∈ [2.0, 3.4]，D-efficiency ∈ [69%, 80%]。
- 切线高估量在新动作集下仍 > 4 nat（代理值高估不会因动作集变化消失）。

## 7. 判定

定义 δI = I_最好 − I_原表（原表 I = 205.03141309913676）。三条互斥：

| 条件 | 处理 |
|---|---|
| δI < 0.5 nat | 报告实际收益，写"本轮未达到预设的 0.5 nat 改进门槛"，主线不动 |
| δI ≥ 0.5 且 g′ < 2 nat | 进 Round 12：用新动作集重做余量（T4 等价表）与两段确认实验，论文主结果换新 |
| δI ≥ 0.5 且 g′ ≥ 2 nat | 作 IV-E 的补充结果报出（"改动作集与切点后 ΔI = X，距名义最优 g′"），主线不动 |

不归因：无论哪格，差距的来源仍不下结论（Round 10 §3）。有限动作集加最多三轮迭代没找到明显收益，只说明本轮搜索得到的收益有限，不说明设计侧不是来源；小于 0.5 nat 的正收益也不写成"未缩小差距"。
